Policies

This directory holds the current rules that future work must continue to enforce.

Name each file <NNNN>-<slug>.md, using the next four-digit number and a kebab-case slug. Required frontmatter is id: policy.<NNNN>, title, and status; optional established-by names the proposal that introduced the policy. The lifecycle is draft → active. When an agreed rule changes, revise its file and keep its ID. When it no longer applies, delete the file after repairing links to it, and never reuse its number. Workbench’s Keeping the Record describes when to write, revise, or retire a policy.
