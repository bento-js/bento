Decisions

This directory holds the current architectural choices and the context that produced them.

Name each file <NNNN>-<slug>.md, using the next four-digit number and a kebab-case slug. Required frontmatter is id: decision.<NNNN>, title, and status; optional established-by names the proposal that introduced the decision. The lifecycle is proposed → accepted. When an agreed choice changes, revise its file and keep its ID. When it no longer applies, delete the file after repairing links to it, and never reuse its number. Workbench’s Keeping the Record describes when to write, revise, or retire a decision.
